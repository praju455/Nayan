# Evaluation

Nayan records only measured benchmark results from synthetic, labelled fixtures. The dashboard reads `shared/eval/results/latest.json`, which is generated by `npm run evaluate` rather than hard-coded display values.

The harness covers the SIH judging dimensions: visual-context agreement, per-category PII precision/recall, bounding-box redaction precision/recall and verification, local core and optional-NER runtime measurements, and PII fixture scan latency. The optional NER assets are counted only after `npm run prepare:ner --workspace=@nayan/extension`; this makes the resource trade-off visible instead of hiding it in a single number. Privacy regressions are blocking: a raw artifact or plaintext PII acceptance is a failed build.

These fixtures establish repeatable regression evidence, not production accuracy claims. Real-device latency, face-redaction quality, and visual-grounding accuracy must be measured against a held-out target-domain corpus before deployment.
