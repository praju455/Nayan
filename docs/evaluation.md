# Evaluation

Nayan records only real benchmark results from synthetic, labelled fixtures. The dashboard reads `shared/eval/results/latest.json`, which is generated by `npm run evaluate` rather than hard-coded display values.

The harness covers the SIH judging dimensions: visual-context agreement, per-category PII precision/recall, redaction verification, local bundle/resource measurements, and end-to-end stage latency. Privacy regressions are blocking: a raw artifact or plaintext PII acceptance is a failed build.
